Privacy Policy

Last updated: 2026-11-08

The Ai Adam publishing tool ("the tool") is a private application used only by the owner of the Ai Adam channel to upload the channel's own videos to its own YouTube and TikTok accounts. It is not offered to the public.

What data the tool accesses

  • OAuth access tokens for the owner's own YouTube and TikTok accounts, used only to upload videos, read basic account info and read the channel's own video statistics.
  • Statistics about the channel's own videos (for example views and retention), used to improve future content.

What the tool does not do

  • It does not collect, store or process personal data of viewers or any other users.
  • It does not sell or share any data with third parties.
  • It does not use data for advertising.

Storage and security

Tokens are stored on the owner's own computers and are never published. Access can be revoked at any time in Google account settings (myaccount.google.com/permissions) or in TikTok settings.

YouTube API Services

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
